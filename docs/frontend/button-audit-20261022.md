## 本次修复

1. 换组绑定最后一次成功请求。跨页返回、取消或新请求失败后，仍能按原结果条件换组，排除已展示影片，不再依赖已被清空的 mutation 临时参数。
2. “什么都行”和六个场景同时清除旧年代、旧排序，界面选项与实际请求一致。
3. 修改片名或年份立即取消旧检索并清除旧状态，可以马上重新查询；晚到响应不能提供错误的影片身份。
4. 回车提交与按钮采用同一校验，非法年份不请求接口，并有可访问的行内提示。
5. 删除检索框和空结果中的虚构片名提示，明确要求来源原文片名，并说明分类榜单范围。
6. 已确认影片或片单后，补充文字留空也可提交，不强迫用户填写可选文本框。
