# 电影选片室：视觉重设计

## 方向

用海岸列车摄影建立电影产品的第一印象。大屏首屏采用宽幅画面与大标题，选片表单紧接主视觉，心情入口成为明确可点击的辅助操作。参考 [MUBI 首页](https://mubi.com/en/hk)的影像优先与克制导航，仅借鉴信息层级，不复用其素材或品牌。

配色：瓷白 #f5f6f8、白 #ffffff、墨蓝 #141b25、深蓝灰 #202a38、琥珀 #f2b86b、雾灰 #aab7c8。浅色模式操作强调色使用深琥珀 #86531c，以保证文字对比度。状态颜色保留语义。

字体：中文以 Microsoft YaHei / PingFang SC 为正文，标题使用同一字体的粗体，避免缺字与远程字体阻塞；首屏标题 36–80px、正文 16–18px，辅助文字 13–14px。正文行高 1.65，标题行高 1.18。间距以 8px 为基础。

```text
宽幅导航：品牌                       选片 / 本次片单 / 偏好与隐私
简短演示状态说明                                      接入状态
┌──────────────────────────────────────────────────────┐
│ 今晚，想看点什么？       海岸列车摄影                   │
│ 给自己留一场电影的时间                                  │
│ 开始选片                  氛围画面说明                  │
└──────────────────────────────────────────────────────┘
┌───────────────────────────────┐  从一个念头开始
│ 三种选片方式                   │  松弛一点
│ 简洁输入与时长 / 地区           │  一起看
│ 隐私说明             获取候选  │  换个世界
└───────────────────────────────┘
候选结果：明确合成标签、资料、理由、来源与未知状态
```

原则：首屏只保留一个视觉焦点；操作区优先易读；宽屏真实利用空间；窄屏重新排版；主题随系统立即变化。氛围摄影不作为电影剧照、海报或真实片源。图片来源和许可证见 [素材记录](assets.md)。图片生成服务返回访问拒绝，没有生成或使用 AI 图片。

## 验收

保留原有真实 HTTP、错误、隐私和会话状态测试；检查 Chrome 1440 / 1920 / 2560 宽屏、390 / 320 窄屏及明暗模式。通过截图逐项检查构图、正文可读性、完整操作区、焦点样式、无横向溢出，再保存最终证据。
