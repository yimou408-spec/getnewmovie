## 最终行为

- 默认使用 Apple 美国区公开榜单，本机模型只负责受限条件提取。影片事实、身份、来源、时长及排序不由模型编造。
- TMDB 鉴权或服务失败时自动切换至 Apple，提示实际来源；没有 TMDB token 也能正常使用。真实 TMDB、云端 DeepSeek 尚未调用验收，它们不参与默认演示。
- 模型下载/启动或请求失败时前端仍能启动和选片。模型解析遗漏硬条件、添加未表达条件、混淆时长上下限等情况会转为规则，页面显示实际解析方法；不支持条件先明确确认。
- 所有资料源均失败时显示可重试错误并保留已有真实结果；海报失败/超时可重试，不导致整张影片卡消失。未知评分、地区渠道等保持未知。
- `.env` 自动读取且终端环境变量优先；配置接口不返回密钥或服务商地址。模型验证状态只在当前进程中实际调用且核对成功后更新，附成功时间。
- 本地模型仅监听 `127.0.0.1:18181`，演示仅监听 `127.0.0.1:8000`。启动器保留端口已被占用的程序，退出时只清理自己创建的模型进程。

## 启动与交付

当前电脑直接访问上述本地网址。日后在项目根目录运行 `start-demo.cmd`；发布包已包含构建页面及验证过的模型/运行时，可用 `start-demo.cmd --no-build` 跳过重新构建。模型权重约 1.1 GB，首次在新电脑安装 Python 依赖及查询真实资料仍需网络；不是独立免安装 EXE。

Apple 的美国区覆盖、源片名及数据字段会影响候选，不保证全片库或中国地区观看渠道。片单、备注、对比保存在当前页面内存，刷新会清空；账号、云端保存、影评与模型个性化排序不在本次实现范围。没有将单次模型探测或这 6 例条件检查解释为推荐质量评测。
