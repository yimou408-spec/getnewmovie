## 组员本地启动

在本分支仓库根目录，Python 3.11+、Node.js 24：

~~~powershell
python -m pip install -r requirements-s0.txt
cd web/app
npm ci
npm run build
cd ../..
python -m uvicorn scripts.movie_preview:app --host 127.0.0.1 --port 8000
~~~

前端 http://127.0.0.1:8000/，健康状态 http://127.0.0.1:8000/api/health。无需 TMDB 密钥，需要能访问 Apple。上述为复现说明，**不表示本机已执行成功**。只发布构建目录，不发布仓库文件；无账号或持久化。
