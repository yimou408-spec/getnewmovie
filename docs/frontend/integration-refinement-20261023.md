## 实际修复与界面调整

- 修复结构化点选心情被当作硬条件的问题：此前“温暖治愈＋剧情＋120分钟”会因家庭/动画类别交集而错误清空。与文字入口统一，类型、年代、时长和排除仍严格执行，心情仅辅助召回及排序；无相关简介线索时明确表示匹配待确认，不编造“类型接近”依据。
- 六个场景移到表单前，桌面横向排列、手机两列；可直接开始真实推荐。心情、类型、时长优先，文字输入放在点选之后，仍为可选。
- 已选条件支持逐项移除，保留其他选择；候选区“修改选片条件”返回表单并聚焦标题，保留已有候选和偏好，不重复请求。
- 首屏缩短，表单使用桌面多列/手机单列；推荐采用桌面三列、手机单列海报卡，突出片名和匹配依据。完整数据边界可展开，单一来源、无豆瓣评分及播放渠道未知始终可见；离线合成与降级结果默认展开说明。
- 延续系统明暗主题、既有组件与品牌色；未引入独立主题覆盖或新框架。依据[设计计划](refinement-plan-20261023.md)执行，并应用 software-product-frontend、frontend-design、web-design-guidelines、webapp-testing 和 React 性能指导。
